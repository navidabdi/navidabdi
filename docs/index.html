Navidabdi-Straße

A corner of Berlin built out of a GitHub history. One building per year, height set by that year's contributions — so the street is a decade of work you can walk down. Drag to orbit, scroll to zoom.

Every object carries a number

The buildings
One per year. Height is that year's contribution total, so the tallest block is the busiest year.
Lit windows
Scale with each building's height. A few glow GitHub green rather than lamp-yellow.
Ampelmännchen
The status light — green, and the plate above says what it means. The figures are the East Berlin ones.
Street sign
Berlin's white enamel plate: the street, the postal district, and house numbers running 1–46, which is the public repository count.
U-Bahn plate
The year the account opened.
S-Bahn plate
Stars earned across public repositories.
Litfaßsäule
The advertising column was invented in Berlin, so it carries the advertising: the profile view count.
Fernsehturm
Alexanderplatz, with its aviation beacon still blinking.
The M10
A tram on rails set into the asphalt, running the length of the street.
